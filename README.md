# 掼蛋宝

微信小程序：4 人掼蛋对局记录、统计、AI 分析。

完全本地存储，不上传服务器，无账号系统。仅 AI 报告功能会调一次 DeepSeek API（用你自己的 Key）。

---

## 是什么

帮你和牌友记录每一次掼蛋对局，不只是"谁赢谁输"，还能逐手追踪整场打到了什么级、谁过的 A、有没有套圈、谁是常驻头游。攒了一定数据后让 DeepSeek 给你写一份带绰号、带故事的"赛季报告"。

## 主要功能

### 记录与回看
- **记一局**：日期、4 个人、组队方式、获胜方、最终比分（含套圈）
- **多手追踪**（核心）：每手按顺序点头/二/三/末游 →
  - 自动算双方升级（双下 +3 / 单下 +2 / 双贡 +1）
  - 自动判定过 A（A1 需双下、A2/A3 双下或单下）
  - A3 头末游自动套圈，回到 3
  - 过 A 后自动填好最终比分和获胜方
- **双下识别**：头+二同队即默认双下，免点 3/4 游
- **草稿自动恢复**：记录中途切走再回来，进度不丢
- **历史回看**：每场对局可下拉展开看逐手详情，过 A 蓝色高亮、套圈棕色标记

### 统计
- 总局数 / 本周局数
- 胜率排行（竞赛名次，保留并列）
- 连胜统计（≥ 3 连胜显示）
- 入榜门槛按牌局独立配置

### 输入输出
- **快速搭配**：从最近对局自动提取 4 人组合，点 chip 一键填好双方（带开关，可关闭）
- **CSV 双向**：完整版（备份 / 朋友互导）、按手展开（看 / 给 AI）
- **范围选择**：全部 / 近 30 天 / 近 100 场 / 自定义日期
- **发送文件**：生成 .csv 直接通过微信分享，电脑 Excel 双击就是表格

### AI 报告（接 DeepSeek）
- 8 个分析角度（可多选）：个人实力 / 搭档协同 / 对抗关系 / 趣味盘点 / 综合全面 / 打牌节奏 / 关键时刻 / 头游榜
- 后台喂给 AI 的统计带手级数据：个人头/末游率、A 关过A率、套圈触发次数等
- 历史报告可回看

## 怎么跑起来

### 前置
- 微信开发者工具
- 微信小程序 appid（开发期可用测试号）
- DeepSeek API Key（仅 AI 报告功能需要，从 [platform.deepseek.com](https://platform.deepseek.com) 取）

### 步骤
1. 克隆这个仓库
   ```bash
   git clone https://github.com/Muscliffe64/dadaojile.git
   ```
2. 微信开发者工具 → 导入项目 → 选 `dadaojile` 文件夹
3. 把 `project.config.json` 里的 `appid` 改成你自己的
4. 想用 AI 报告：进首页底部 "⚙️ 设置" → 填 DeepSeek API Key
5. 发版前在小程序后台 → 开发设置 → 服务器域名 添加 `https://api.deepseek.com`

## 项目结构

```
pages/
  index/         首页：统计 + 排行榜 + 最近对局 + 入口按钮
  record/        记录对局（核心，含多手追踪）
  history/       对局历史
  players/       参与人管理
  tables/        牌局（赛季/分组）管理
  leaderboard/   完整排行榜
  import/        数据导入与导出
  api-config/    设置：DeepSeek API Key + 上榜门槛
  report-config/ AI 报告：选牌局、选侧重、生成
  report-list/   历史 AI 报告列表
  report-view/   单份报告查看
utils/
  storage.js     本地存储 + 统计计算
  aiReport.js    DeepSeek 调用 + CSV 导出
  importCsv.js   CSV 导入解析
  handsReplay.js 手史回放规则（共用给 history/index/record）
  config.js      常量
images/          图片资源
app.js / app.json / app.wxss   全局配置
```

## CSV 数据格式

数据全部存在用户本地 `wx.storage`，不上传服务器。导出 CSV 时格式如下，顶部注释行说明列编码：

```
# v=2 手数过程列：每手 4 位数字 = 头/二/三/末游的座位号；1=甲1, 2=甲2, 3=乙1, 4=乙2
日期,甲1,甲2,乙1,乙2,获胜方,比分,头游,二游,三游,末游,手数过程
2026-05-17,董媛,孙丰元,姬航宇,关山,A,A1:3 2队套圈,董媛,孙丰元,姬航宇,关山,4132;2134;3214;...
```

老版本（无注释、无 "手数过程" 列、或用姓名编码的旧 CSV）继续兼容导入。

## 隐私

- **不收集任何使用数据**——没有服务器、没有埋点
- 所有对局记录只存在你的微信本地
- DeepSeek API Key 也只存本地，仅在你主动生成报告时使用
- AI 报告功能会把对局 CSV 通过 DeepSeek 官方接口发送给他们处理，详见 [DeepSeek 隐私政策](https://platform.deepseek.com)
